# llm-cold-start-recsys
University of Michigan MADS Capstone Project for Team Cold Start - Using (L)LMs to Speed-up the Warmup Curve for Cold-Start Recommendation

## design_documents folder
### initial_pipeline_design
This folder contains:
1. `baseline_steel_thread_cf.py`
    - Jupytext file to generate steel thread Jupyter notebook `baseline_steel_thread_cf.ipynb`
2. `baseline_steel_thread_cf.ipynb`
    - Steel thread Jupyter notebook generated by `baseline_steel_thread_cf.py`
3. `build_solution_architecture.py`
    - .py file to generate solution architecture diagram `solution_architecture_generated.html` 
4. `diagram_lib.py`
    - Helper functions py to generate `solution_architecture_generated.html` 
5. `requirements.txt` 
    - Requirements file
6. `solution_architecture_generated.html`
    - Solution architecture diagram generated by `build_solution_architecture.py`

These are files used during the initial design of the project to establish extreme baseline cases and validate the steel thread architecture.
